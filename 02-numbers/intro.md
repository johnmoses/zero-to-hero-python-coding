# Numbers & Binary

Python's numeric types and binary data.

## Numbers

Python has three numeric types: `int`, `float`, and `complex`.

## Binary, Octal & Hexadecimal

Numbers can be represented in different bases. Python provides built-in functions to convert between them: `bin()`, `oct()`, `hex()`, `int()`.

## Files

- `intro.py` — numeric types and operations
- `cast.py` — type casting
- `maths.py` — math operations
- `binary.py` — binary, octal, hexadecimal conversions
